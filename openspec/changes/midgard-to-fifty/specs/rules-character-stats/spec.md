## ADDED Requirements

### Requirement: The class table holds the four new classes
The class table SHALL give the Spiritmaster, Bonedancer, Hunter and Shadowblade their primary, secondary and tertiary stats, base hit points, weapon skill base, spec point multiplier, casting stat (where they have one) and base class (Mystic, Mystic, Rogue, Rogue). Each number SHALL carry its source and status in the rule book. Status: provisional unless the findings give a published 1.65 account.

#### Scenario: Spiritmaster and Bonedancer numbers
- **WHEN** the class table is read for the Spiritmaster (27) and the Bonedancer (30)
- **THEN** each gives piety, dexterity and quickness as primary, secondary and tertiary stats, 560 base hit points, weapon skill base 280, a spec multiplier of 10 and the Mystic base, with the races the data's start table gives (Norseman and Kobold Spiritmasters; Troll, Kobold and Valkyn Bonedancers)

#### Scenario: Shadowblade numbers
- **WHEN** the class table is read for the Shadowblade
- **THEN** it gives the Shadowblade's stats, hit points, weapon skill base and spec multiplier as recorded in the rule book, with their status

#### Scenario: Casting stat
- **WHEN** the class table is read for the Spiritmaster and the Bonedancer
- **THEN** both cast from piety

### Requirement: The character sheet carries concentration
The character sheet SHALL include the concentration pool size and the amount in use for a class with spells. Neither field SHALL appear for a class without spells.

#### Scenario: A Bonedancer's sheet
- **WHEN** a Bonedancer holding one concentration buff receives their sheet
- **THEN** it shows their pool and the buff's cost in use
