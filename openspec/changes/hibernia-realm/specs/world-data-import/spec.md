## ADDED Requirements

### Requirement: Hibernia regions imported
`dbimport` SHALL import the population of Hibernia's regions (classic Hibernia, Hy Brasil, Tir na Nog and Hibernia's dungeons), with the same not-classic filtering as Midgard.

#### Scenario: Population
- **WHEN** `dbimport` runs and the server starts
- **THEN** the creatures of Hibernia's starting zones are in the world
